# ⚡ Eletro Kurumin — Sistema de Controle de Estoque

## 📌 Sobre o Projeto

O **Eletro Kurumin** é um sistema de controle de estoque desenvolvido para uma empresa de componentes eletrônicos. O objetivo é facilitar o gerenciamento dos produtos, permitindo organizar os componentes cadastrados, controlar quantidades e acompanhar o valor total do estoque.

O sistema foi desenvolvido utilizando tecnologias de desenvolvimento web e banco de dados MySQL.

## 🚀 Funcionalidades

- **Autenticação:** Login de usuários utilizando e-mail e senha.
- **Cadastro de usuários:** Registro de novos usuários no sistema.
- **Cadastro de componentes:** Adicionar novos componentes eletrônicos.
- **Listagem:** Visualizar todos os componentes cadastrados.
- **Edição:** Atualizar informações dos componentes.
- **Exclusão:** Remover componentes do estoque.
- **Categorias:** Organização dos componentes por categorias.
- **Relatório de estoque:** Exibição da quantidade total de componentes e do valor total dos produtos cadastrados.
